# Intelligent Teaching Platform

## 项目简介

智能化在线教学支持服务平台（教师中心系统），旨在辅助教师进行课程管理、作业管理、测评分析以及教学效果评估，提高教学效率与质量。

---

## 项目结构

```
intelligent-teaching-platform
│
├── backend/   # 后端（Spring Boot）
└── frontend/  # 前端（Vue3）
```

---

## 技术栈

### 前端

* Vue3
* Vue Router
* Pinia
* Vite

### 后端

* Spring Boot

---

## 功能模块

* 网站门户
* 课程管理
* 课程资源管理
* 作业管理
* 测评管理
* 成绩管理
* 实训管理
* 问卷调查管理
* 教学效果评价
* 问题中心

---

## 智能算法模块

* 图像分类：作业/试卷自动分类、客观题辅助批改
* 目标检测：检测抄袭及违规行为
* 对话大模型：辅助备课、生成试题、教学分析建议
* 语音识别（ASR）：语音录入试题、语音批改
* 语音合成（TTS）：评语与通知语音播报
* 图像分割：提取课件与试题关键内容


使用 IDEA 打开 `backend` 目录，运行 Spring Boot 主类。
